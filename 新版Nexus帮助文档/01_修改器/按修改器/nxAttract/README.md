# nx 吸引（nxAttract）

当前文档版本：NeXus `2026.0.0`

`nx 吸引（nxAttract）` 让粒子朝一个或多个目标位置移动。目标可以来自修改器对象自身，也可以来自吸引器（Attractors）列表中的场景对象。它适合制作粒子汇聚、追向移动目标、分流到多个目标，以及从目标位置向外排斥的效果。

## 一条容易跑通的起步方法

1. 使用 `nx 发射器（nxEmitter）` 产生一批会持续移动的粒子。
2. 添加 `nx 吸引（nxAttract）`，并把它接入这批粒子的修改器流程。
3. 暂时保持吸引器（Attractors）列表为空，让修改器对象自身的位置充当目标。
4. 保持默认速度（Velocity）类型、力（Force）`30`、加速度（Acceleration）`3`、速度限制（Speed Limit）`2.5`。
5. 把 `nx 吸引（nxAttract）` 对象移到粒子前方，从同一帧开始播放，观察粒子是否转向并汇聚到该位置。
6. 临时关闭修改器启用（Enabled），对比粒子是否恢复原来的运动线路。
7. 需要指定其他目标时，把场景对象加入吸引器（Attractors）列表，再通过对象选择（Object Select）决定怎样选择目标。

修改参数或目标位置后，应从同一帧重新开始模拟。粒子的速度和位置已经被此前结果改变时，继续播放无法得到可靠对比。

## 目标从哪里来

吸引器（Attractors）列表为空，或列表里没有可用的启用对象时，目标是 `nx 吸引（nxAttract）` 对象自身的世界位置。移动修改器对象就能移动吸引点。

列表中存在可用的启用对象时，目标改由这些对象的位置提供。此时对象选择（Object Select）决定每个粒子使用哪个目标。目标对象的网格形状不会形成吸引表面，粒子读取的是对象位置。

## 类型（Type）

类型（Type）决定吸引怎样加入粒子的运动。当前插件默认使用速度（Velocity）。

### 速度（Velocity）

速度（Velocity）直接控制粒子朝目标移动的速度，转向和汇聚会更直接。需要粒子明确追向目标，或希望快速得到稳定的汇聚线路时，可以先使用这一类型。

其他修改器已经为粒子建立复杂运动时，速度（Velocity）会更明显地接管运动方向。需要保留风力、重力或湍流共同影响时，可以改用力（Force）进行比较。

### 力（Force）

力（Force）把吸引作为一项力加入现有运动。粒子原来的惯性和其他力仍会参与最终结果，因此轨迹通常会弯向目标，并可能从目标附近掠过。

需要吸引与 `nx 重力（nxGravity）`、`nx 风力（nxWind）` 或 `nx 湍流（nxTurbulence）` 共同塑造轨迹时，可以从力（Force）类型开始调整。

## 力（Force）

力（Force）控制整体吸引力度。当前插件默认值是 `30`；拖动时的常用范围是 `-300` 到 `300`，数值框允许输入这个范围以外的值。

- 正值让粒子朝目标移动
- 正值提高后，粒子更快改变方向并靠近目标
- 正值降低后，吸引较弱，粒子原来的运动更容易保留下来
- 值为 `0` 时，不会产生朝向目标的吸引力
- 负值会把作用方向翻转，粒子从目标位置向外远离；负值的绝对值越大，排斥越强

粒子突然急转或穿过目标后高速甩开时，先降低力（Force），再检查加速度（Acceleration）和速度限制（Speed Limit）。

## 加速度（Acceleration）

加速度（Acceleration）控制粒子朝目标运动时，速度增加或减少得有多快。当前插件默认值是 `3`；拖动时的常用范围是 `-30` 到 `30`，数值框允许输入这个范围以外的值。

- 值提高后，粒子更快增加朝向目标的速度，汇聚过程会缩短
- 值降低但仍大于 `0` 时，粒子需要更长时间才能达到较高速度，转弯和靠近过程更缓慢
- 值为 `0` 时，不再通过这一参数继续增加朝向目标的速度
- 负值会让粒子朝目标运动时减速

粒子需要先保留一段原有运动，再逐渐弯向目标时，可以降低加速度（Acceleration）。希望粒子迅速追上移动目标时，可以逐步提高它，同时用速度限制（Speed Limit）控制最高速度。

## 速度限制（Speed Limit）

速度限制（Speed Limit）限制受吸引粒子能够达到的最高速度。当前插件默认值是 `2.5`，最小值是 `0`；拖动时的常用上限是 `10`，数值框允许输入更高数值。

- 值提高后，粒子可以继续加速到更高速度，更快到达目标，也更容易穿过目标后继续前冲
- 值降低后，粒子会更早停止加速，接近目标的过程更慢
- 值为 `0` 时，吸引无法建立大于零的目标速度，通常看不到粒子被带向目标

提高力（Force）或加速度（Acceleration）后，粒子速度仍不再增加，通常已经到达速度限制（Speed Limit）。需要加快移动时，应先检查这一上限。

## 三个数值怎样一起判断

- 力（Force）决定整体拉向目标的力度，也决定正向吸引或负向排斥
- 加速度（Acceleration）决定朝目标的速度经过多长时间增加或减少
- 速度限制（Speed Limit）决定这段运动最终允许达到多快

常见调整顺序：

1. 先用力（Force）建立清楚可见的吸引方向。
2. 用加速度（Acceleration）调整粒子达到较高速度所需的时间。
3. 用速度限制（Speed Limit）压住过高速度。
4. 粒子仍然会高速越过目标时，再配合 `nx 阻力（nxDrag）` 减少前冲。

## 对象选择（Object Select）

对象选择（Object Select）在吸引器（Attractors）列表包含多个目标时，决定每个粒子朝哪个位置移动。当前插件默认使用最近（Nearest）。

### 最近（Nearest）

最近（Nearest）让每个粒子选择离自己最近的目标。粒子移动后，最近目标可能发生变化，轨迹会在不同目标的影响区域之间转向。

它适合让粒子自动流向附近目标。多个目标距离接近时，粒子可能在运动过程中切换目标。

### 最远（Furthest）

最远（Furthest）让每个粒子选择离自己最远的目标。粒子位置变化后，最远目标也可能发生变化。

它适合把粒子引向场景中相距较远的目标。目标切换时，轨迹可能出现明显转折。

### 平均（Average）

平均（Average）先计算所有可用目标位置的平均点，再让全部受影响粒子朝这个平均点移动。

例如两个目标分别位于左右两侧时，平均点通常位于两者之间。移动任一目标都会移动最终吸引点。

### 索引（Index）

索引（Index）让粒子使用列表中的一个指定目标。第一项的索引是 `0`，第二项是 `1`，后续依次增加。

需要整批粒子始终追向同一个明确目标时，可以使用这一模式。调整列表顺序后，应重新检查索引（Index）指向的对象。

### 随机（Random）

随机（Random）让每个粒子从吸引器（Attractors）列表中随机选择一个目标。它适合把一批粒子分散到多个目标，最终每个目标附近可以形成一部分汇聚结果。

## 索引（Index）参数

索引（Index）参数只在对象选择（Object Select）设为索引（Index）时显示。当前插件默认值是 `0`，最小值是 `0`；拖动时的常用上限是 `1000`，数值框允许输入更高数值。

- 值为 `0` 时选择列表第一项
- 值提高 `1` 会选择下一项
- 值需要对应当前可用目标的实际位置

目标被删除、禁用或重新排序后，原索引可能指向另一项或超出可用列表。索引模式没有得到预期目标时，先检查列表顺序和各项启用状态。

## 吸引器（Attractors）列表

吸引器（Attractors）列表保存用于提供目标位置的场景对象。可以加入一个或多个对象，也可以单独关闭某一项的启用状态。

- 只有存在并且已经启用的列表项会提供目标位置
- 所有列表项都不可用时，修改器对象自身的位置会重新成为目标
- 当前插件最多把前 `1024` 个可用目标同步到吸引计算中
- 平均（Average）只使用实际参与计算的目标位置

目标对象可以移动或制作动画，吸引位置会随对象的世界位置变化。目标对象的缩放和网格细节不会改变吸引位置。

## 修改器启用（Enabled）

修改器启用（Enabled）控制整个 `nx 吸引（nxAttract）` 是否参与粒子流程。关闭后，吸引停止执行，现有参数和目标列表会保留。

## 视口可见（Visible in Editor）

开启视口可见（Visible in Editor）后，修改器对象位置会显示一个圆环和四个箭头。力（Force）为正值或 `0` 时，箭头朝向圆环中心；力（Force）为负值时，箭头朝外。

这组图形用于提示修改器自身的位置和力的正负方向，不会作为可渲染几何体出现。吸引器（Attractors）列表已经提供其他目标时，实际目标仍由列表和对象选择（Object Select）决定。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 发射器（nxEmitter）` 提供粒子的出生位置和初始运动。初始速度越高，吸引需要越大的力（Force）或更长时间才能让粒子明显转向。判断吸引效果时，应同时检查发射器的初始方向和速度。

### 和 nx 重力（nxGravity）

`nx 重力（nxGravity）` 的效果朝向会给受影响粒子统一的平行方向，`nx 吸引（nxAttract）` 会根据每个粒子与目标之间的位置分别计算方向。两者同时使用时，粒子会在下落和靠近目标之间形成弯曲轨迹。

### 和 nx 湍流（nxTurbulence）

力（Force）类型更容易保留 `nx 湍流（nxTurbulence）` 形成的摆动。湍流过强时，粒子可能长期无法靠近目标；可以降低湍流强度，或提高吸引的力（Force）。

### 和 nx 阻力（nxDrag）

`nx 阻力（nxDrag）` 会逐渐减弱粒子的运动速度。粒子靠近目标后仍高速越过并来回摆动时，可以适当增加阻力。阻力过强会让粒子靠近目标的过程明显变慢。

### 和 nx 速度（nxSpeed）及 nx 限制（nxLimit）

`nx 速度（nxSpeed）` 可以继续改变粒子速率，`nx 限制（nxLimit）` 可以设置额外的速度范围。多个位置都在限制速度时，应同时检查吸引的速度限制（Speed Limit）和 `nx 限制（nxLimit）`，较低的有效上限会更早阻止粒子继续加速。

### 和 nx 自旋（nxSpin）

吸引会改变粒子的运动方向。使用实例模型并希望模型持续朝向前进方向时，添加 `nx 自旋（nxSpin）`，并使用切向（Tangential）层控制粒子旋转。

### 和 nx 推力（nxPush）

把力（Force）设为负值，可以让粒子从吸引目标向外远离。`nx 推力（nxPush）` 会根据粒子彼此之间的距离把过近粒子分开。一个目标中心向外排斥使用负吸引力，整理粒子之间的间距使用推力。

### 和 nx 衰减（nxFalloff）

`nx 衰减（nxFalloff）` 可以限制吸引在哪个空间区域生效。只希望粒子进入某个区域后才被目标拉走时，可以使用衰减范围控制作用位置。

### 和 nx 拖尾（nxTrail）

`nx 拖尾（nxTrail）` 可以显示粒子弯向目标、汇聚或切换目标的连续轨迹。检查最近（Nearest）和最远（Furthest）的目标切换时，拖尾比单帧粒子位置更容易看出转折。

### 和 nx 缓存（nxCache）

修改类型、数值、目标列表或对象位置后，旧缓存仍可能回放此前结果。吸引设置已经改变但粒子轨迹没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 粒子完全没有被吸引

按下面顺序检查：

1. `nx 发射器（nxEmitter）` 是否正在产生粒子
2. `nx 吸引（nxAttract）` 是否已经接入同一批粒子的修改器流程
3. 修改器启用（Enabled）是否打开
4. 力（Force）是否大于 `0`
5. 加速度（Acceleration）和速度限制（Speed Limit）是否大于 `0`
6. 组（Groups Affected）或衰减（Falloff）是否排除了当前粒子
7. 吸引器（Attractors）列表中的目标是否存在并已启用
8. `nx 缓存（nxCache）` 是否仍在回放旧结果

### 粒子朝修改器对象移动，没有朝列表目标移动

检查吸引器（Attractors）列表中是否至少有一个存在并已启用的对象。所有列表项都不可用时，修改器会使用自身位置。还应检查对象选择（Object Select）和索引（Index）是否指向预期目标。

### 粒子经过目标后继续来回摆动

降低力（Force）或加速度（Acceleration），降低速度限制（Speed Limit），并适当增加 `nx 阻力（nxDrag）`。这些调整会减少粒子接近目标时保留的前冲速度。

### 多个目标之间出现突然转向

最近（Nearest）和最远（Furthest）会随着粒子位置重新判断目标。需要固定目标时，改用索引（Index）；需要所有目标共同形成一个稳定吸引点时，使用平均（Average）。

### 修改器图标在一个位置，粒子却飞向另一个位置

视口辅助图形始终画在修改器对象上。吸引器（Attractors）列表中存在可用对象时，实际目标来自列表。检查对象选择（Object Select）当前选择了哪个目标。

### 粒子从目标向外散开

检查力（Force）是否为负值。负值会把吸引方向翻转为向外排斥，改回正值后粒子会重新朝目标移动。
