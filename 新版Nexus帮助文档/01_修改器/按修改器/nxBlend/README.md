# nx 混合（nxBlend）

当前文档版本：NeXus `2026.0.0`

`nx 混合（nxBlend）`读取每颗粒子附近的其他粒子，把选中的粒子属性逐渐拉向邻域的共同结果。它适合平滑粒子之间突兀的半径、颜色、缩放、质量或旋转差异，也适合让两股粒子在相遇区域形成连续过渡。

`nx 混合（nxBlend）`只改变界面中列出的五种粒子属性。粒子的位置和运动速度不在当前修改范围内。

## 一条容易判断的起步方法

1. 使用 `nx 发射器（nxEmitter）`产生两组颜色或尺寸不同的粒子。
2. 添加 `nx 混合（nxBlend）`，先保持混合（Blend）为法线方向（Normal）。
3. 把距离（Distance）设为能覆盖相邻粒子的范围。
4. 保持颜色（Color）默认 `100%`，先观察相遇区域是否出现平滑过渡。
5. 需要平滑其他属性时，再逐项提高半径（Radius）、缩放（Scale）、质量（Mass）或旋转（Rotation）。

## 设置

### 已启用（Enabled）

已启用（Enabled）控制整个修改器。关闭后，所有混合结果停止计算，修改器和参数仍会保留。

### 混合（Blend）

混合（Blend）决定邻居属性怎样参与当前粒子的结果，默认使用法线方向（Normal），即按邻域值进行平均。还可选择加法（Addition）、减去（Subtract）、相乘（Multiply）、差值（Difference）、屏幕（Screen）和叠加（Overlay）。

法线方向（Normal）适合平滑属性差异；加法（Addition）、减去（Subtract）和其他模式会产生更明显的合成变化，适合需要风格化结果时使用。

### 距离（Distance）

距离（Distance）默认 `0.1 m`，决定每颗粒子搜索邻居的半径。提高后会纳入更远的粒子，颜色、尺寸或其他属性会在更大范围内逐渐接近；降低后只会在紧密相邻的粒子之间产生变化。

场景中的粒子间距大于距离（Distance）时，粒子找不到有效邻居，当前属性不会产生明显混合。提高距离后，参与计算的邻居数量和计算范围也会增加。

### 强度（Strength）

强度（Strength）默认 `10%`，控制每个属性向邻域结果靠近的幅度。低值只轻微削弱差异；提高后属性更快接近周围粒子的共同值；`100%`表示完整执行当前混合，继续提高到 `1000%`会得到夸张的合成结果。

强度（Strength）会与下面每个属性的混合量一起生效。属性混合量设为 `0%`时，即使总强度很高，该属性也不会改变。

### 最大混合（Max Blend）

最大混合（Max Blend）默认 `300`帧，决定粒子年龄达到什么时间后停止混合。年龄超过这个时间的粒子会保留当时的属性结果。

降低最大混合（Max Blend）后，混合只发生在粒子出生后的早期阶段，适合让粒子出生时先统一颜色或尺寸，随后保持结果。数值行旁的帧/秒切换可以在帧数和秒数之间选择单位。

## 各属性混合量

下面五项都是百分比，并且都会继续受到总强度（Strength）影响。设为 `0%`时保留当前属性；提高后，该属性更明显地向邻域值靠近。

### 半径（Radius）

半径（Radius）默认 `0%`，控制粒子物理半径向邻居半径靠近的程度。提高后，相邻粒子的计算尺寸差异会减小；它不会直接改变粒子位置。

### 缩放（Scale）

缩放（Scale）默认 `0%`，控制粒子缩放向邻居缩放靠近的程度。提高后，相邻实例模型的大小或轴向比例会更接近。需要看到实例大小变化时，下游需要使用 `nx 生成器（nxGenerator）`的粒子缩放（Particle Scale）来源。

### 质量（Mass）

质量（Mass）默认 `0%`，控制粒子质量向邻居质量靠近的程度。提高后，同一局部区域内粒子的质量差别会减小，后续受力响应也会更接近。

### 旋转（Rotation）

旋转（Rotation）默认 `0%`，控制粒子旋转向邻居旋转靠近的程度。提高后，邻近粒子的朝向差异会减小。需要实例模型跟随粒子旋转时，`nx 生成器（nxGenerator）`的旋转源（Rotation Source）要使用粒子（Particle）。

### 颜色（Color）

颜色（Color）默认 `100%`，因此新建修改器后最先看到的通常是粒子颜色变得更平滑。提高保持默认值会让相邻颜色继续相互接近；降低后颜色过渡减弱；设为 `0%`时颜色保持原有分布。

## 组（Groups Affected）、映射（Mapping）和衰减（Falloff）

组（Groups Affected）可以把 `nx 混合（nxBlend）`限制到指定的 `nx 组（nxGroup）`。列表为空时影响所有可用粒子；加入组后，只处理这些组中的粒子。

映射（Mapping）可以让粒子数据动态改变距离（Distance）、强度（Strength）或各属性混合量。它适合让不同粒子拥有不同的平滑范围或混合力度。

衰减（Falloff）使用一个或多个 `nx 衰减（nxFalloff）`限制空间作用区域。粒子位于有效衰减区域外时，不会接受当前混合结果。

## 常见问题

### 粒子颜色没有混合

检查颜色（Color）是否仍为 `100%`，距离（Distance）是否覆盖相邻粒子，以及粒子是否确实进入了当前修改器的组（Groups Affected）和衰减（Falloff）范围。

### 混合范围太大

降低距离（Distance）或衰减范围。距离过大时，远处粒子也会进入邻域，颜色和尺寸变化会跨越更大的空间。

### 粒子位置没有改变

这是当前修改器的正常范围。`nx 混合（nxBlend）`处理粒子属性，位置和速度需要交给 `nx 方向（nxDirection）`、`nx 速度（nxSpeed）`或其他运动修改器。
