# nx 阻力（nxDrag）

当前文档版本：NeXus `2026.0.0`

`nx 阻力（nxDrag）` 模拟粒子穿过空气、水和其他介质时受到的阻力。阻力会沿粒子当前运动的反方向降低速度，让高速粒子逐渐慢下来。

阻力大小由下面这些数据共同决定：

- 介质密度：由密度（Density）和密度值（Density Value）决定
- 外形受到介质阻碍的程度：由阻力系数（Drag Coefficient）和阻力系数值（Drag Coeff. Value）决定
- 整体效果比例：由强度倍增器（Strength Multiplier）决定
- 每个粒子的当前速度（Speed）、半径（Radius）和质量（Mass）

速度更高、半径更大或质量更轻的粒子通常减速更明显。粒子静止时没有需要抵消的运动，阻力不会主动把粒子推向某个方向。

## 一条容易跑通的起步方法

1. 使用 `nx 发射器（nxEmitter）` 发射一批具有明显初始速度的粒子。
2. 添加 `nx 阻力（nxDrag）`，并把它接入这批粒子的修改器流程。
3. 保持默认空气（Air）、球体（Sphere）和强度倍增器（Strength Multiplier）`100%`。
4. 播放时间线，观察粒子飞行距离和速度下降过程。
5. 临时关闭修改器启用（Enabled），对比粒子关闭阻力后是否飞得更远。
6. 将介质改成水（Water），再次播放并观察粒子是否更快减速。
7. 需要微调整体效果时，恢复适合的介质，再调整强度倍增器（Strength Multiplier）。

比较阻力前后结果时，应从同一帧重新开始模拟。继续播放旧结果会混入之前已经积累的速度变化。

## 密度（Density）

密度（Density）选择粒子正在穿过的介质。当前插件默认使用空气（Air），对应密度值（Density Value）`1.205 kg/m³`。

- 密度提高后，同样速度、半径和质量的粒子会更快失去速度
- 密度降低后，粒子会保留更多原有速度，飞行距离更长
- 选择真空（Vacuum）后，密度值为 `0`，当前修改器不会产生介质阻力

选择预设时，插件会自动载入对应的密度值（Density Value），下方数值框会变成不可编辑状态。需要手动输入数值时，选择自定义（Custom）。

### 气体和真空预设

- 真空（Vacuum）：`0`
- 空气（Air）：`1.205`
- 二氧化碳（Carbon Dioxide）：`1.842`
- 氦气（Helium）：`0.1664`
- 氪气（Krypton）：`3.74`
- 氙（Xenon）：`5.86`

### 液体预设

- 丙烷（液化）（Propane (Liquified)）：`494`
- 石脑油（Naphtha）：`665`
- 汽油（Gasoline (Petrol)）：`737`
- 乙醇（Ethanol）：`789`
- 水（Water）：`1000`
- 甘油（Glycerine）：`1259`
- 海水（Sea Water）：`1025`
- 重水（Heavy Water）：`1105`
- 糖蜜（Treacle）：`1600`
- 溴（Bromine）：`3120`
- 汞（Mercury）：`13590`

这些数值用于载入介质密度。预设名称提供一个物理介质起点，最终减速程度仍会受到阻力系数、强度倍增器和粒子自身数据影响。

## 密度值（Density Value）

密度值（Density Value）是阻力计算使用的介质密度，单位为 `kg/m³`。它只在密度（Density）选择自定义（Custom）时可以编辑。当前插件最小值是 `0`，拖动滑块时的常用上限是 `2000`，数值框允许继续输入更高数值。

- 值提高后，粒子减速更快
- 值降低后，粒子减速更慢
- 值为 `0` 时，不会产生介质阻力

介质名称符合需求，但效果需要统一加强或减弱时，可以保留预设并调整强度倍增器（Strength Multiplier）。只有需要指定明确密度数值时，才需要使用自定义（Custom）。

## 阻力系数（Drag Coefficient）

阻力系数（Drag Coefficient）选择一个外形预设。当前插件默认使用球体（Sphere），对应阻力系数值（Drag Coeff. Value）`0.5`。

- 较低系数表示外形更容易穿过介质，粒子会保留更多速度
- 较高系数表示外形更容易受到介质阻碍，粒子会更快减速
- 系数只提供计算数值，插件不会检查粒子实例模型是否真的具有该预设名称对应的外形

选择预设时，插件会自动载入对应的阻力系数值（Drag Coeff. Value），下方数值框会变成不可编辑状态。需要使用自己的系数时，选择自定义（Custom）。

### 外形预设

- 海豚（Dolphin）：`0.0036`
- 导弹（Missile）：`0.01`
- 战斗机（Fighter Aircraft）：`0.016`
- 轿车（Saloon Car）：`0.29`
- 鸟（Bird）：`0.4`
- 球体（Sphere）：`0.5`
- 立方体（Cube）：`0.8`
- 自行车（Bicycle）：`0.9`
- 自行车与骑手（Bicycle and Rider）：`1.1`
- 人类（直立）（Human (Upright)）：`1.15`
- 摩托车与骑手（Motorcycle and Rider）：`1.8`
- 矩形框（Rectangular Box）：`2.1`
- xpShatter 碎片（xpShatter Fragments）：`1.5`

粒子代表小球或近似圆形颗粒时，可以从球体（Sphere）开始。粒子代表扁平碎片或不规则破碎块时，可以尝试 xpShatter 碎片（xpShatter Fragments），再根据实际飞行距离调整。

## 阻力系数值（Drag Coeff. Value）

阻力系数值（Drag Coeff. Value）是阻力计算使用的外形系数。它只在阻力系数（Drag Coefficient）选择自定义（Custom）时可以编辑。当前插件最小值是 `0`，拖动滑块时的常用上限是 `3`，数值框允许继续输入更高数值。

- 值提高后，粒子更快失去速度
- 值降低后，粒子更容易保持原有速度
- 值为 `0` 时，当前外形系数不会产生阻力

密度（Density）说明粒子穿过什么介质，阻力系数（Drag Coefficient）说明粒子外形怎样受到介质阻碍。两者相乘参与阻力计算，其中任意一项为 `0` 都会让当前阻力消失。

## 强度倍增器（Strength Multiplier）

强度倍增器（Strength Multiplier）统一放大或缩小最终阻力。当前插件默认值是 `100%`，最小值是 `0%`；拖动滑块时的常用上限是 `1000%`，数值框允许继续输入更高数值。

- `100%` 按当前密度、阻力系数和粒子数据计算阻力
- 值提高后，所有受影响粒子都会更快减速
- 值降低后，所有受影响粒子都会保留更多速度
- 值为 `0%` 时，当前修改器不会施加阻力

已经选好介质和外形，只需要调整画面中的整体减速节奏时，优先使用强度倍增器（Strength Multiplier）。这样可以保留预设代表的介质和外形关系。

## 粒子速度、半径和质量怎样影响结果

密度、阻力系数和强度倍增器相同时，不同粒子仍可能以不同速度减速。阻力还会读取每个粒子的速度（Speed）、半径（Radius）和质量（Mass）。

- 速度（Speed）更高时，粒子受到的阻力更明显，高速部分会先被压低
- 半径（Radius）更大时，粒子用于计算阻力的表面积更大，减速更明显
- 质量（Mass）更高时，同样阻力更难改变粒子速度，粒子会继续飞得更远
- 质量（Mass）更低时，同样阻力更容易改变粒子速度，粒子会更快慢下来

同一批粒子减速差异很大时，先检查发射器中的速度、半径和质量是否带有变化量，再检查映射或其他修改器是否修改了这些粒子数据。

## 修改器启用（Enabled）

修改器启用（Enabled）控制 `nx 阻力（nxDrag）` 是否参与粒子模拟。关闭后，当前修改器不会继续降低粒子速度，其他力修改器仍会正常作用。

## 视口可见（Visible in Editor）

当前插件的 `nx 阻力（nxDrag）` 没有专用视口辅助图形。切换视口可见（Visible in Editor）不会改变阻力计算，也不会隐藏粒子模拟结果。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 阻力（nxDrag）` 需要接入正在产生粒子的修改器流程。发射器中的速度（Speed）、半径（Radius）和质量（Mass）都会改变阻力结果。

判断参数时可以先关闭这些数据的随机变化，让粒子使用统一初始值；阻力节奏确认后，再恢复变化量。

### 和 nx 重力（nxGravity）

`nx 重力（nxGravity）` 会持续沿固定方向增加粒子速度，阻力会持续降低当前运动速度。两者同时作用时，粒子加速会逐渐受到阻力压制。

粒子下落过快时，可以降低重力强度或提高阻力；粒子刚开始下落就显得迟缓时，可以降低阻力强度倍增器。

### 和 nx 风力（nxWind）

`nx 风力（nxWind）` 持续推动粒子，`nx 阻力（nxDrag）` 会根据粒子的当前速度产生减速。风力负责建立运动方向和推动力度，阻力负责限制粒子保持高速运动的能力。

需要较强风向但不希望粒子无限加速时，可以保留风力方向，再逐步提高阻力。

### 和 nx 湍流（nxTurbulence）及 nx 涡度（nxVorticity）

`nx 湍流（nxTurbulence）` 和 `nx 涡度（nxVorticity）` 会持续改变粒子速度。加入阻力后，高速弯折和旋流会更快衰减，轨迹通常更收敛。

细节运动被阻力压得过弱时，先降低强度倍增器（Strength Multiplier），再判断是否需要提高湍流或涡度强度。

### 和 nx 限制（nxLimit）

`nx 阻力（nxDrag）` 根据粒子运动状态逐渐减速。`nx 限制（nxLimit）` 的速度（Speed）层直接约束允许的速度范围。

希望运动自然衰减时使用阻力；需要明确最高速度时，可以继续加入速度（Speed）层。两者同时使用时，阻力负责减速过程，速度层负责最终边界。

### 和 nx 拖尾（nxTrail）

`nx 拖尾（nxTrail）` 可以显示连续运动轨迹。阻力提高后，拖尾的前进距离会缩短，粒子后段轨迹也会更快收拢。

### 和 nx 缓存（nxCache）

修改密度、阻力系数、强度倍增器或发射器粒子数据后，旧缓存仍可能回放此前结果。参数已经改变但飞行距离没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 粒子完全没有减速

按下面顺序检查：

1. `nx 发射器（nxEmitter）` 是否正在产生具有速度的粒子
2. `nx 阻力（nxDrag）` 是否已经接入同一批粒子的修改器流程
3. 修改器启用（Enabled）是否打开
4. 密度（Density）是否选择了真空（Vacuum）
5. 自定义密度值（Density Value）是否为 `0`
6. 自定义阻力系数值（Drag Coeff. Value）是否为 `0`
7. 强度倍增器（Strength Multiplier）是否为 `0%`
8. `nx 缓存（nxCache）` 是否仍在回放旧结果

### 粒子出生后立刻停住

先降低强度倍增器（Strength Multiplier）。结果仍然过强时，再检查密度预设、阻力系数预设以及粒子的质量（Mass）和半径（Radius）。

### 同一批粒子的减速程度不一致

检查发射器中的速度（Speed）、半径（Radius）和质量（Mass）是否存在变化量。较快、较大或较轻的粒子会更快减速。

### 密度值或阻力系数值无法编辑

密度值（Density Value）只在密度（Density）选择自定义（Custom）后可以编辑。阻力系数值（Drag Coeff. Value）只在阻力系数（Drag Coefficient）选择自定义（Custom）后可以编辑。

### 选择某个外形预设后，实例模型没有变化

外形预设只会载入对应的阻力系数值。它不会修改粒子显示的模型，也不会分析模型几何形状。

### 关闭阻力后，粒子仍然在减速

检查其他修改器是否正在改变速度，并检查碰撞、流体或速度限制设置。还要确认 `nx 缓存（nxCache）` 没有继续回放带有减速结果的旧缓存。
