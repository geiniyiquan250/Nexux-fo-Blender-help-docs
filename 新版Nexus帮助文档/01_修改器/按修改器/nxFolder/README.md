# nx 文件夹（nxFolder）

当前文档版本：NeXus `2026.0.0`

`nx 文件夹（nxFolder）`用于整理 NeXus 管线列表中的修改器。它管理名称、颜色、层级、折叠和整组启用状态，不产生粒子，也不执行物理计算。

## 使用方法

在三维视图侧栏的 NeXus 管线列表中，从添加菜单创建文件夹。使用增加缩进把修改器或子文件夹放到文件夹下，使用减少缩进移出当前层级。

### 名称和颜色

文件夹设置可以编辑名称和图标颜色。颜色只用于列表识别，不改变粒子、修改器或渲染结果。

### 展开和折叠

折叠后子项暂时隐藏，计算和启用状态保持不变。再次展开即可继续查看和编辑。

### 已启用（Enabled）

关闭文件夹会临时关闭其直接子项，并记录关闭前的启用状态；重新开启时恢复仍属于该文件夹的直接子项。它适合快速对比一组修改器的整体效果。

### 移动与层级

上移和下移会让文件夹连同全部后代一起移动。增加缩进会把当前项放到上一项下方，减少缩进会提升一级。插件会阻止让文件夹成为自身后代的循环层级。

### 删除

删除文件夹会连同其子文件夹和修改器一起删除。执行前应先确认选中的列表行和完整子层级。

## 常见问题

### 折叠文件夹后效果仍然存在

折叠只隐藏列表内容。需要停止整组修改器时，关闭文件夹的已启用（Enabled）。

### 重新启用后某个修改器没有恢复

恢复只处理仍属于该文件夹的直接子项。检查该修改器是否在关闭期间被移动到其他层级。
