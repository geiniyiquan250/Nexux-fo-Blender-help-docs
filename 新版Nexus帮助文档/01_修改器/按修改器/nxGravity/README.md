# nx 重力（nxGravity）

当前文档版本：NeXus `2026.0.0`

`nx 重力（nxGravity）` 给粒子持续施加一个固定方向的加速度。粒子受力时间越长，沿重力方向积累的速度越大。

它适合制作以下运动：

- 粒子自然下落
- 粒子向上漂升
- 粒子沿斜向持续加速
- 整批粒子朝一个移动目标所在方向偏转

## 先看懂重力方向

重力方向沿 `nx 重力（nxGravity）` 对象自身的局部负 Z 轴。视口中的红色箭头会直接显示当前方向。

- 旋转重力对象，红色箭头和重力方向会一起改变
- 移动重力对象不会自动让粒子朝它聚拢
- 设置效果朝向（Effect Towards）后，重力对象会自动转向指定目标

重力方向决定粒子往哪里加速，强度（Strength）决定加速有多快。调整方向时先看红色箭头，调整下落或上升速度时再看强度（Strength）。

## 一条容易跑通的起步方法

1. 先让 `nx 发射器（nxEmitter）` 产生一批粒子。
2. 添加 `nx 重力（nxGravity）`，并把它接入这批粒子的修改器流程。
3. 保持默认强度（Strength）`9.81`、变化（Variation）`0`。
4. 播放时间线，观察粒子是否沿红色箭头方向持续加速。
5. 旋转重力对象，确认粒子运动方向跟着改变。
6. 基础方向确认后，再加入变化（Variation）或效果朝向（Effect Towards）。

如果关闭其他力修改器后粒子开始稳定沿红色箭头移动，说明重力已经正常生效，原来的复杂轨迹来自多个修改器共同作用。

## 强度（Strength）

强度（Strength）控制重力加速度大小。当前插件默认值是 `9.81`，可以作为接近常见地球表面重力的起点。

- 值提高后，粒子速度增加得更快，下落或上升轨迹会更快拉长
- 值降低后，粒子需要更长时间才能形成明显速度
- 值为 `0` 时，当前重力不会继续改变粒子速度

强度（Strength）会持续累积到粒子运动上。粒子刚开始变化不明显时，可以继续播放几帧观察；粒子后期速度过高时，可以降低强度（Strength），或使用 `nx 限制（nxLimit）` 控制速度范围。

## 变化（Variation）

变化（Variation）给重力强度加入随机差异。当前插件默认值是 `0`。

- 值为 `0` 时，所有受影响粒子使用统一的重力强度
- 值提高后，不同粒子或不同帧获得的重力强度差异更明显
- 值过高时，整批粒子的加速节奏会变得松散，部分粒子可能明显快于其他粒子

想让雨滴、尘埃或碎片拥有轻微不同的下落速度时，可以从较小数值开始增加。需要整齐、稳定的统一重力时，保持为 `0`。

## 变化量模式（Variation Mode）

变化量模式（Variation Mode）决定变化（Variation）在什么时候重新取值。

### 每粒子（Per Particle）

每粒子（Per Particle）为每个粒子分配一个固定的强度差异。当前插件默认使用这个模式。

- 同一个粒子的重力差异会保持稳定
- 不同粒子之间可以出现不同的加速速度
- 轨迹通常更连续，适合雨滴、碎片和尘埃

### 每帧（Per Frame）

每帧（Per Frame）让随机差异随帧改变。

- 同一个粒子的重力强度会随时间变化
- 变化（Variation）提高后，粒子更容易出现忽快忽慢的运动
- 适合不稳定重力、脉动加速或需要持续扰动的效果

变化（Variation）为 `0` 时，两种变化量模式（Variation Mode）都会得到相同的统一重力结果。

## 随机种（Seed）

随机种（Seed）改变变化（Variation）使用的随机排列。当前插件默认值是 `12345`。

- 保持其他参数不变并修改随机种（Seed），可以得到另一套粒子强度差异
- 使用相同随机种（Seed）时，随机结果可以保持可重复
- 变化（Variation）为 `0` 时，修改随机种（Seed）通常看不到变化

随机种（Seed）只负责更换随机分布，不会直接提高或降低整体重力强度。

## 效果朝向（Effect Towards）

效果朝向（Effect Towards）指定一个目标对象，让重力对象的局部负 Z 轴自动朝向目标。

设置目标后：

- 插件会给重力对象添加标准追踪约束（Track To Constraint）
- 目标移动时，重力方向会继续跟随目标位置变化
- 红色箭头会显示更新后的统一重力方向
- 手动旋转重力对象时，最终朝向仍会受到标准追踪约束（Track To Constraint）控制

清空效果朝向（Effect Towards）后，插件创建的标准追踪约束（Track To Constraint）会被移除，重力方向重新由对象自身旋转决定。

### 目标朝向和目标吸引的区别

效果朝向（Effect Towards）根据重力对象与目标对象的位置计算一条统一方向。所有受影响粒子都会沿这条平行方向加速。

需要让每个粒子分别朝目标位置聚拢时，使用 `nx 吸引（nxAttract）`。它会读取粒子与吸引目标之间的位置关系，形成朝目标汇聚的轨迹。

## 视口辅助图标

`nx 重力（nxGravity）` 在视口中显示圆形标记和红色方向箭头。

- 红色箭头指出局部负 Z 轴，也就是当前重力方向
- 关闭视口可见（Visible in Editor）后，辅助图标会隐藏，重力计算仍会继续
- 场景中有多个重力对象时，可以通过各自箭头快速检查方向

如果粒子朝向与预期相反，先看红色箭头，再检查效果朝向（Effect Towards）是否仍然指定了目标。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 重力（nxGravity）` 需要接入粒子的修改器流程，才能影响这批粒子。发射器已经产生粒子，但重力完全没有效果时，先检查发射器的修改器列表是否包含它。

### 和 nx 碰撞体（nxCollider）

重力会让粒子持续撞向某个方向，`nx 碰撞体（nxCollider）` 决定粒子接触表面后的反弹、滑动和停留方式。

粒子落到地面后持续弹跳时，通常同时检查重力强度（Strength）、弹力（Bounce）和摩擦力（Friction）。

### 和 nx 粒子-粒子碰撞（nxPPCollisions）

重力会把粒子持续压向同一区域，`nx 粒子-粒子碰撞（nxPPCollisions）` 会继续处理粒子之间的挤压和分离。

堆积结果抖动或爆开时，需要同时检查重力强度（Strength）、粒子半径和粒子碰撞的子步（Substeps）与迭代（Iterations）。

### 和 nx 自旋（nxSpin）

重力改变粒子的运动速度和运动方向。实例模型需要跟随下落或上升方向时，添加 `nx 自旋（nxSpin）` 的切向（Tangential）层。

### 和 nx 流体（nxFluids）

液体快速设置会检查场景中是否已经存在 `nx 重力（nxGravity）`。场景中没有重力对象时，快速设置会自动创建一个，因此执行液体快速设置后看到新增重力对象属于正常结果。

### 和 nx 泡沫（nxFoam）

`nx 泡沫（nxFoam）` 的重力（Gravity）可以指定一个 `nx 重力（nxGravity）`。喷雾会沿这个方向下落，气泡会沿相反方向上升。

泡沫重力（Gravity）留空时，会使用场景中的第一个重力对象。泡沫系统会自行处理这项重力，链接的重力不会再次重复施加到泡沫粒子上。

### 和 nx 缓存（nxCache）

修改重力强度、变化方式或方向后，旧缓存仍可能回放此前结果。参数已经改变但粒子轨迹没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 粒子完全不受重力影响

按下面顺序检查：

1. `nx 发射器（nxEmitter）` 是否正在产生粒子
2. `nx 重力（nxGravity）` 是否已经接入粒子的修改器流程
3. 修改器是否启用
4. 强度（Strength）是否为 `0`
5. `nx 缓存（nxCache）` 是否仍在回放旧结果

### 粒子朝错误方向移动

先看视口中的红色箭头。如果箭头方向也有问题，检查重力对象旋转和效果朝向（Effect Towards）。设置了目标时，标准追踪约束（Track To Constraint）会持续控制对象朝向。

### 粒子下落速度不一致

检查变化（Variation）是否大于 `0`。需要每个粒子保持固定差异时，选择每粒子（Per Particle）；需要每帧变化时，选择每帧（Per Frame）。

### 粒子开始很慢，后面越来越快

这是持续加速度产生的正常结果。降低强度（Strength）可以减慢速度累积；需要限制最终速度时，可以使用 `nx 限制（nxLimit）`。

### 设置目标后，粒子没有汇聚到目标点

效果朝向（Effect Towards）给整批粒子提供统一的平行重力方向。需要每个粒子朝目标位置聚拢时，改用 `nx 吸引（nxAttract）`。
