# nx 限制（nxLimit）

当前文档版本：NeXus `2026.0.0`

`nx 限制（nxLimit）` 把粒子的运动或数据约束在指定范围内。它采用限制层结构，可以分别限制速度方向、位置、缩放、旋转、整体速率、半径、质量和用户值，并让多个限制层按顺序共同处理粒子。

新建 `nx 限制（nxLimit）` 时，插件会自动添加一个速度（Velocity）层。这个默认层已经启用，但 X、Y、Z 三轴的限制都设为无（None），因此刚添加修改器时通常看不到粒子运动变化。需要先选择限制方向或添加其他层，再设置实际边界。

## 一条容易跑通的起步方法

下面用速度（Speed）上限限制粒子最高速率：

1. 使用 `nx 发射器（nxEmitter）` 产生一批具有明显初始速度的粒子。
2. 添加 `nx 限制（nxLimit）`，并把它接入这批粒子的修改器流程。
3. 在层列表中添加速度（Speed）层。
4. 打开范围最大值（Range Max），把值（Value）设为低于粒子当前速率的数值。
5. 保持变化（Variation）`0%`、混合模式（Blend Mode）为法线方向（Normal）、混合强度（Blend Strength）`100%`。
6. 从同一帧重新播放，观察高速粒子是否被压到统一上限。
7. 临时关闭这一层，确认粒子关闭限制后重新恢复较高速度。

需要最低速率时再打开范围最小值（Range Min）。同时启用上下限后，两项共同形成允许的速度区间。

## 层列表怎样处理

每个限制层只处理一种粒子属性。层会从列表底部向顶部依次计算，上层会接着处理下层已经得到的结果。

- 当前层的已启用（Enabled）关闭后，当前层保留在列表中，但不参与计算
- 层类型（Layer Type）决定当前层限制哪一种属性
- 混合模式（Blend Mode）决定当前层怎样与下方层结果结合
- 混合强度（Blend Strength）决定当前层参与结果的比例，默认 `100%`，范围是 `0%` 到 `100%`

混合强度（Blend Strength）降低后，当前层对最终结果的约束会减弱；设为 `0%` 时，这一层不会改变下方结果。刚开始使用时先保留法线方向（Normal）和 `100%`，确认单层结果后再叠加其他层。

混合模式（Blend Mode）提供法线方向（Normal）、添加（Add）、减去（Subtract）、相乘（Multiply）、差值（Difference）、屏幕（Screen）、叠加（Overlay）、最小（Min）和最大（Max）。这些模式用于组合多个限制层。单层限制或不同属性各用一层时，优先保留法线方向（Normal）；只有需要同类限制层相互组合时，再调整其他模式并逐层对比。

## 每层衰减（Falloff）

每个限制层都有自己的常规（General）页和衰减（Falloff）页。衰减（Falloff）控制当前层在场景中的生效区域，不会同时限制其他层。

可以添加盒体（Box）、线性（Linear）、球体（Sphere）和噪波（Noise）衰减，也可以在同一层组合多个衰减。只想在局部区域限制速度或位置时，应把衰减加到对应层，并单独检查该层的范围。

## 速度（Velocity）层

速度（Velocity）层按 X、Y、Z 三轴分别限制速度分量，适合禁止粒子朝某个轴的反方向移动，或压缩某一轴上的运动范围。它会改变运动方向分量，和限制整体快慢的速度（Speed）层用途不同。

### 坐标（Coordinates）

坐标（Coordinates）决定 X、Y、Z 轴来自哪个空间，默认是发射器（Emitter）。

- 发射器（Emitter）：使用发射器自身坐标轴；旋转发射器后，限制方向会跟着改变
- 世界（World）：使用场景固定的世界坐标轴
- 自定义对象（Custom Object）：使用指定物体的坐标轴

选择自定义对象（Custom Object）后，物体（Object）字段才会显示作用。该字段为空时缺少自定义坐标参考，应先指定一个物体。

### 范围最小值与范围最大值

范围最小值（Range Min）和范围最大值（Range Max）分别为 X、Y、Z 轴设置速度分量范围，使用 `0%` 到 `100%` 的百分比。变化（Variation）为对应轴加入 `0%` 到 `100%` 的随机差异。

这些范围要和下方轴限制一起使用。轴限制保持无（None）时，该轴不会受到方向约束，单独修改百分比通常看不到预期结果。

### X、Y、Z 轴限制

X 轴限制（X-Axis Restriction）、Y 轴限制（Y-Axis Restriction）和 Z 轴限制（Z-Axis Restriction）各自提供三种选择：

- 无（None）：不限制这一轴
- 正向：只允许该轴的正方向速度
- 负向：只允许该轴的负方向速度

例如，世界（World）坐标下把 Z 轴限制（Z-Axis Restriction）设为正向后，粒子只保留世界 Z 轴正方向的速度分量。其他两轴保持无（None）时，水平运动仍可继续。

### 无倾斜（No Banking）

无倾斜（No Banking）开启后，粒子沿弯曲路径运动时不会随路径产生侧倾。实例模型沿轨迹转弯时出现不需要的左右倾斜，可以启用这个选项。

## 位置（Position）层

位置（Position）层把粒子约束在指定轴向边界、范围或固定坐标上。它可以限制一个方向、形成三维活动区域，也可以把某一轴锁到固定位置。

### 坐标系统（Coordinate System）

坐标系统（Coordinate System）决定位置数值从哪里开始计算，默认是发射器（Emitter）。

- 发射器（Emitter）：相对于发射器的位置和坐标轴
- 世界（World）：使用世界坐标
- 粒子（Particle）：相对于每个粒子的出生位置
- 自定义对象（Custom Object）：相对于指定物体

选择自定义对象（Custom Object）后，需要在物体（Object）中指定参考对象。参考对象移动或旋转时，限制区域也会使用更新后的坐标空间。

### X、Y、Z 位置限制

X 限制（X Restriction）、Y 限制（Y Restriction）和 Z 限制（Z Restriction）使用相同规则：

- 无（None）：这一轴不限制位置
- 正向：粒子位置不能低于最小值
- 负向：粒子位置不能高于最大值
- 范围（Range）：粒子位置保持在最小值和最大值之间
- 固定（Fixed）：把粒子锁在指定轴坐标

选择正向后显示对应最小值和变化；选择负向后显示对应最大值和变化；选择范围（Range）后同时显示最小值、最大值及各自变化；选择固定（Fixed）后只显示固定坐标。

例如，只想让粒子保持在地面上方，可以在世界（World）坐标中给 Z 轴选择正向，并把 Z 最小值设为地面高度。需要把粒子压在一个平面上时，可以把某一轴设为固定（Fixed）。

## 缩放（Scale）层

缩放（Scale）层限制粒子三轴缩放的最小值和最大值。范围最小值（Range Min）和范围最大值（Range Max）都是独立开关，默认均关闭。

- 打开范围最小值（Range Min）后，值（Value）设置 X、Y、Z 三轴缩放下限
- 打开范围最大值（Range Max）后，值（Value）设置 X、Y、Z 三轴缩放上限
- 变化 X、Y、Z（Variation X/Y/Z）为对应轴的边界加入 `0%` 到 `100%` 随机差异

只打开下限时，粒子不会继续缩到该值以下；只打开上限时，粒子不会继续放大到该值以上；两者同时打开后形成允许的缩放区间。

实例模型被 `nx 缩放（nxScale）` 放大或缩小时，可以用这一层控制最终尺寸范围。上下限都关闭时，这一层不会限制缩放。

## 旋转（Rotation）层

旋转（Rotation）层限制粒子在正向和负向可以达到的角度。模式（Mode）默认使用世界（World）。

- 世界（World）：按世界空间旋转限制
- 相对（Relative）：按粒子自身轴向解释旋转限制

### 链接通道（Link Channels）

链接通道（Link Channels）默认关闭。

- 开启后，航向、俯仰和倾斜共用一组正向与负向限制
- 关闭后，通过通道（Channel）分别编辑航向（Heading）、俯仰（Pitch）和倾斜（Banking）

正向（Positive）和负向（Negative）是两侧限制的独立开关。开启某一侧后，对应的正向限制（Positive Limit）或负向限制（Negative Limit）才会参与计算；数值以角度显示。变化（Variation）范围是 `0%` 到 `100%`，用于给该侧角度边界加入随机差异。

只希望阻止粒子向一侧继续旋转时，可以只开启这一侧。需要把旋转保持在双向角度区间内时，同时启用正向和负向限制。

实例模型的真实粒子旋转由 `nx 自旋（nxSpin）` 等旋转修改器产生时，旋转（Rotation）层可以继续约束最终角度范围。

## 速度（Speed）层

速度（Speed）层限制粒子整体运动速率，不区分 X、Y、Z 方向。它最适合设置最低速度、最高速度或一个允许的速率区间。

- 打开范围最小值（Range Min）后，低于值（Value）的粒子会被提高到最低速率
- 打开范围最大值（Range Max）后，高于值（Value）的粒子会被压到最高速率
- 两者同时打开后，粒子速率保持在上下限之间
- 变化（Variation）范围是 `0%` 到 `100%`，用于让不同粒子的边界产生随机差异

所有开关默认关闭，数值默认 `0`。只想防止重力、风力、湍流或涡度让粒子越来越快时，通常只需要开启范围最大值（Range Max）。

## 半径（Radius）层

半径（Radius）层限制粒子半径。它的范围最小值（Range Min）、范围最大值（Range Max）、值（Value）和变化（Variation）与速度（Speed）层使用相同的上下限规则。

- 下限防止粒子继续缩小
- 上限防止粒子继续变大
- 同时启用后形成允许的半径区间

半径会影响粒子显示，也可能影响碰撞、邻居搜索、阻力和网格化结果。限制后画面或模拟发生连带变化时，应同时检查使用粒子半径的其他修改器。

## 质量（Mass）层

质量（Mass）层限制粒子质量。它使用范围最小值（Range Min）、范围最大值（Range Max）、值（Value）和变化（Variation）设置质量区间。

- 下限把过轻的粒子提高到最低质量
- 上限把过重的粒子压到最高质量
- 同时启用后，质量保持在上下限之间

质量会改变粒子对阻力和其他力的反应。限制质量后，原来轻重差异明显的粒子可能表现得更接近。

## 用户值（User Value）层

用户值（User Value）层限制粒子的自定义用户数据通道。它使用与速度（Speed）层相同的范围最小值（Range Min）、范围最大值（Range Max）、值（Value）和变化（Variation）。

只有其他修改器、映射或问题系统正在读取用户值（User Value）时，这一层才会带来可见的间接结果。场景中没有功能使用该数据时，修改用户值通常看不到粒子外观或运动变化。

## 已启用（Enabled）

已启用（Enabled）控制整个 `nx 限制（nxLimit）` 是否参与粒子流程。关闭后，所有限制层都会停止作用，层设置仍会保留。

## 视口可见（Visible in Editor）

当前插件的 `nx 限制（nxLimit）` 没有专用视口辅助图形。切换视口可见（Visible in Editor）不会改变限制计算，也不会隐藏粒子模拟结果。

## 组（Groups Affected）

组（Groups Affected）把 `nx 限制（nxLimit）` 限制到指定的 `nx 组（nxGroup）`。列表为空时处理所有可用粒子；加入组后，只约束这些组中的粒子数据。

## 映射（Mapping）

映射（Mapping）用粒子自身的数据驱动可映射的限制参数，让不同粒子使用不同边界或限制程度。具体可映射参数以当前映射列表为准。

## 衰减（Falloff）

这里的衰减（Falloff）使用一个或多个 `nx 衰减（nxFalloff）` 对象限制整个修改器。每层衰减（Falloff）只控制当前限制层，两级范围会依次参与最终结果。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 限制（nxLimit）` 需要接入正在产生粒子的修改器流程。发射器提供初始速度、半径和质量，限制层可以在粒子进入流程后约束这些数据。

### 和力修改器

`nx 重力（nxGravity）`、`nx 风力（nxWind）`、`nx 湍流（nxTurbulence）` 和 `nx 涡度（nxVorticity）` 都可能持续改变粒子速度。速度（Speed）上限可以控制最终速率，速度（Velocity）层可以继续限制允许的轴向。

### 和 nx 阻力（nxDrag）

`nx 阻力（nxDrag）` 根据粒子状态逐渐降低速度，速度（Speed）层直接设置允许的速率边界。需要自然减速过程时先调整阻力；需要明确最高速度时再使用范围最大值（Range Max）。

### 和 nx 自旋（nxSpin）

`nx 自旋（nxSpin）` 控制粒子的真实旋转，旋转（Rotation）层约束旋转角度。模型需要继续跟随运动方向时，应保留自旋设置，再用限制层控制允许的旋转范围。

### 和 nx 缩放（nxScale）

`nx 缩放（nxScale）` 改变粒子缩放，缩放（Scale）层设置最终上下限。粒子需要继续生长但不能超过指定尺寸时，可以只启用范围最大值（Range Max）。

### 和 nx 粒子-粒子碰撞（nxPPCollisions）及 nx 网格化（nxMesher）

半径（Radius）层改变粒子半径后，粒子间距、碰撞接触和网格表面都可能随之变化。半径限制已经生效但碰撞或网格结果异常时，应一起检查这些修改器使用的半径相关设置。

### 和 nx 缓存（nxCache）

修改层类型、边界、层顺序或混合设置后，旧缓存仍可能回放此前结果。设置已经改变但粒子数据没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 新建后粒子没有变化

这是默认设置产生的结果。新建修改器只有一个速度（Velocity）层，X、Y、Z 三轴都设为无（None）。选择至少一个轴向限制，或添加速度（Speed）、位置（Position）等其他层并启用实际边界。

### 设置最高速度后仍然没有效果

按下面顺序检查：

1. 使用的是速度（Speed）层
2. 范围最大值（Range Max）已经打开
3. 值（Value）低于粒子当前速率
4. 当前层的已启用（Enabled）已经打开
5. 混合强度（Blend Strength）大于 `0%`
6. 当前层衰减（Falloff）没有排除粒子所在区域
7. `nx 限制（nxLimit）` 已经接入粒子的修改器流程
8. `nx 缓存（nxCache）` 没有回放旧结果

### 速度方向限制和预期相反

先检查坐标（Coordinates）。发射器（Emitter）和自定义对象（Custom Object）会使用对象自身旋转后的轴向，世界（World）使用固定世界轴。随后检查该轴选择的是正向还是负向。

### 粒子被压在一个平面或边界上

检查位置（Position）层。固定（Fixed）会把对应轴锁到指定坐标，范围（Range）会把粒子保持在最小值和最大值之间。

### 上下限已经填写，但结果仍不受限制

速度（Speed）、缩放（Scale）、半径（Radius）、质量（Mass）和用户值（User Value）层都需要先打开范围最小值（Range Min）或范围最大值（Range Max）。数值框中存在数值时，对应开关仍决定该边界是否生效。

### 多层结果难以判断

层从底部向顶部处理。先临时关闭上层，从最底层开始逐层恢复，并把混合模式（Blend Mode）设为法线方向（Normal）、混合强度（Blend Strength）设为 `100%`。确认每层单独结果后，再调整混合方式。
