# nx 推力（nxPush）

当前文档版本：NeXus `2026.0.0`

`nx 推力（nxPush）` 检查彼此距离过近的粒子，并把它们相互推开，直到达到设定间距。它适合减少粒子出生时的重叠、整理密集粒子分布，或让大小不同的粒子保持与自身半径相符的空隙。

推开方向来自粒子之间的位置关系。修改器对象的位置和旋转不会形成一个向外发射推力的中心。

## 一条容易跑通的起步方法

1. 使用 `nx 发射器（nxEmitter）` 在较小区域内产生一批密集粒子。
2. 添加 `nx 推力（nxPush）`，并把它接入这批粒子的修改器流程。
3. 保持默认绝对（Absolute）模式、距离（Distance）`0.1`、强度（Strength）`50%`、迭代（Iterations）`5`。
4. 从同一帧播放，观察重叠粒子是否逐渐分开。
5. 临时关闭已启用（Enabled），对比关闭后粒子是否重新堆叠在一起。
6. 粒子仍有明显重叠时，先提高迭代（Iterations），再小幅提高强度（Strength）。
7. 粒子半径存在变化时，把距离模式（Distance Mode）切换为粒子半径（Particle Radius），观察大小不同的粒子是否得到更合适的间距。

比较前后结果时应从同一帧重新开始模拟。推力会改变粒子位置，继续播放旧状态会保留此前已经推开的结果。

## 距离模式（Distance Mode）

距离模式（Distance Mode）决定粒子间距怎样计算。当前插件默认使用绝对（Absolute）。

### 绝对（Absolute）

绝对（Absolute）对所有粒子使用统一距离（Distance）。

- 适合半径相同或需要整齐固定间距的粒子
- 粒子半径差异较大时，大粒子之间可能仍有重叠，小粒子之间可能留下较大空隙
- 距离（Distance）会保持可编辑

### 粒子半径（Particle Radius）

粒子半径（Particle Radius）读取各粒子的半径来决定推开距离。

- 大粒子会使用更大的分离范围
- 小粒子可以保持更近的间距
- 发射器中的半径变化会直接改变每个粒子的推开范围
- 距离（Distance）会显示为不可编辑，因为当前间距改由粒子半径计算

粒子大小有明显变化时，粒子半径（Particle Radius）通常更容易得到均匀的视觉空隙。需要所有粒子共享明确数值时，使用绝对（Absolute）。

## 距离（Distance）

距离（Distance）只在距离模式（Distance Mode）为绝对（Absolute）时生效。当前插件默认值是 `0.1`，最小值是 `0`；在常见公制场景中，`0.1` 个场景长度单位对应 `10` 厘米（cm）。

- 值提高后，粒子会被推到更远的位置，最终空隙增大
- 值降低后，粒子允许靠得更近
- 值为 `0` 时，没有大于零的目标间距，通常看不到推开效果

距离（Distance）决定目标间距。强度（Strength）决定粒子接近这个目标间距的速度，迭代（Iterations）决定每帧重复修正多少轮。

## 强度（Strength）

强度（Strength）控制粒子被推开的速度。当前插件默认值是 `50%`，范围是 `0%` 到 `100%`。

- 值提高后，重叠粒子会更快分开
- 值降低后，粒子会用更长时间逐渐达到目标间距
- 值为 `0%` 时，当前修改器不会推动粒子

强度（Strength）不会改变距离（Distance）设定的目标空隙。希望粒子最终分得更远时调整距离；希望粒子更快达到当前距离时调整强度。

密集粒子在一帧内突然散开时，可以降低强度（Strength），或提高缓入（Ease In），让推力逐渐增强。

## 迭代（Iterations）

迭代（Iterations）控制每帧重复执行多少轮粒子分离修正。当前插件默认值是 `5`，最小值是 `2`；拖动数值时的常用上限是 `20`，数值框允许继续输入更高数值。

- 值提高后，密集区域会经过更多轮修正，粒子间距更准确，残留重叠更少
- 值降低后，计算更快，拥挤区域可能无法在当前帧内完全分开
- 粒子数量较多时，提高迭代会增加计算时间

默认值 `5` 可以作为普通场景的起点。粒子只有少量重叠时先保持默认；多层粒子相互挤压、提高强度仍有残留重叠时，再逐步提高迭代（Iterations）。

## 缓入（Ease In）

缓入（Ease In）控制推力从开始作用到达到完整强度所需的时间。当前插件默认值是 `0`，最小值是 `0`。

- 值为 `0` 时，推力一开始就按完整强度作用
- 值提高后，推力会经过更长时间逐渐增强，粒子分开过程更柔和
- 缓入时间过长时，粒子在开始阶段可能继续保持重叠，需要更多时间才会完全分开

粒子出生时非常密集并突然爆开，可以先增加缓入（Ease In）。需要从第一帧立即清理重叠时，保持 `0`。

## 仅同组（Only Same Group）

仅同组（Only Same Group）决定不同粒子组之间是否互相推开，当前插件默认关闭。

- 关闭时，进入当前修改器计算的所有粒子可以相互推开
- 开启时，每个粒子只会被同组粒子推开，不同组之间可以靠近或重叠

组（Groups Affected）和仅同组（Only Same Group）负责两个不同阶段：

- 组（Groups Affected）先筛选哪些粒子进入当前修改器
- 仅同组（Only Same Group）再决定这些粒子能否跨组互相推开

例如，组（Groups Affected）同时包含橙色组和蓝色组时，开启仅同组（Only Same Group）后，橙色粒子只与橙色粒子保持间距，蓝色粒子只与蓝色粒子保持间距。

## 五个参数怎样一起判断

- 距离模式（Distance Mode）决定间距来自固定值还是粒子半径
- 距离（Distance）决定绝对模式下的目标间距
- 强度（Strength）决定推开过程有多快
- 迭代（Iterations）决定每帧重复修正多少轮
- 缓入（Ease In）决定推力需要多久达到完整强度

常见调整顺序：

1. 先根据粒子大小选择距离模式（Distance Mode）。
2. 绝对（Absolute）模式下先确定距离（Distance）。
3. 用强度（Strength）调整分开速度。
4. 密集区域仍有残留重叠时，提高迭代（Iterations）。
5. 粒子开始时突然散开，再增加缓入（Ease In）。

## 已启用（Enabled）

已启用（Enabled）控制整个 `nx 推力（nxPush）` 是否参与粒子流程。关闭后，修改器停止执行粒子间距修正，现有参数会保留。

## 视口可见（Visible in Editor）

当前插件的 `nx 推力（nxPush）` 没有专用视口辅助图形。切换视口可见（Visible in Editor）不会改变推开计算，也不会隐藏粒子模拟结果。

## 组（Groups Affected）

组（Groups Affected）决定哪些粒子交给 `nx 推力（nxPush）` 处理。列表为空时处理所有可用粒子；加入组后，只处理这些组中的粒子。

仅同组（Only Same Group）继续决定被处理粒子是否只与同组粒子相互推开。两个设置一起使用时，先由组（Groups Affected）筛选粒子，再按仅同组（Only Same Group）决定配对范围。

## 映射（Mapping）

映射（Mapping）用粒子自身的数据驱动可映射的推力参数，让不同粒子得到不同推开距离或推开强度。具体可映射参数以当前映射列表为准。

## 衰减（Falloff）

衰减（Falloff）使用一个或多个 `nx 衰减（nxFalloff）` 对象限制推力的作用区域。这样可以只整理指定空间内的密集粒子。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 发射器（nxEmitter）` 决定粒子的出生位置、数量和半径。发射区域越小、同一时间出生的粒子越多，`nx 推力（nxPush）` 需要处理的重叠越密集。

粒子一出生就猛烈散开时，应同时检查发射数量、发射区域、粒子半径、推力距离和强度。粒子半径存在变化时，可以使用粒子半径（Particle Radius）模式。

### 和 nx 粒子-粒子碰撞（nxPPCollisions）

`nx 推力（nxPush）` 直接整理粒子间距，提供距离、强度和迭代控制。`nx 粒子-粒子碰撞（nxPPCollisions）` 继续处理粒子接触后的弹力、摩擦、散射和堆积稳定性。

只需要减少重叠或形成均匀空隙时，可以先使用推力。需要粒子碰撞后反弹、滑动或形成物理堆积时，再使用粒子-粒子碰撞。

### 和 nx 阻力（nxDrag）

推力会让重叠粒子产生分离运动，`nx 阻力（nxDrag）` 会逐渐降低这部分速度。粒子被推开后继续漂得太远时，可以适当增加阻力；阻力过强导致粒子迟迟无法达到目标间距时，应降低阻力或提高推力强度。

### 和 nx 速度（nxSpeed）及 nx 限制（nxLimit）

`nx 速度（nxSpeed）` 会继续改变粒子速率，`nx 限制（nxLimit）` 可以设置最终速度上限。推开过程造成粒子速度过高时，可以用 `nx 限制（nxLimit）` 的速度（Speed）层控制最高速率。

### 和 nx 衰减（nxFalloff）

衰减（Falloff）可以限制推力在哪个区域生效。只想让粒子离开发射口后保持间距，或只清理局部拥挤区域时，可以添加对应空间衰减。

### 和 nx 拖尾（nxTrail）

`nx 拖尾（nxTrail）` 可以显示推开过程的连续轨迹。强度提高后，轨迹会更快向周围分散；缓入提高后，轨迹前段的分离幅度会更小。

### 和 nx 缓存（nxCache）

修改距离模式、距离、强度、迭代或缓入后，旧缓存仍可能回放此前结果。参数已经改变但粒子间距没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 粒子完全没有被推开

按下面顺序检查：

1. `nx 发射器（nxEmitter）` 是否正在产生彼此接近的粒子
2. `nx 推力（nxPush）` 是否已经接入同一批粒子的修改器流程
3. 已启用（Enabled）是否打开
4. 强度（Strength）是否大于 `0%`
5. 绝对（Absolute）模式下距离（Distance）是否大于 `0`
6. 粒子半径（Particle Radius）模式下粒子半径是否具有有效数值
7. 组（Groups Affected）、仅同组（Only Same Group）或衰减（Falloff）是否排除了当前粒子组合
8. `nx 缓存（nxCache）` 是否仍在回放旧结果

### 粒子仍有少量重叠

先确认目标距离符合粒子大小，再提高迭代（Iterations）。分开速度过慢时可以继续小幅提高强度（Strength）。粒子半径差异较大时，改用粒子半径（Particle Radius）模式。

### 粒子突然向四周爆开

降低强度（Strength），增加缓入（Ease In），并检查绝对（Absolute）模式下距离（Distance）是否远大于粒子实际尺寸。发射器在同一位置生成过多粒子时，也应降低出生密度。

### 不同组的粒子仍然互相穿插

检查仅同组（Only Same Group）是否开启。开启后，不同组之间不会互相推开；需要所有受影响组彼此保持距离时，应关闭该选项。

### 提高迭代后模拟明显变慢

每增加一次迭代，当前帧都会多执行一轮粒子分离修正。先使用默认值 `5`，只在密集区域仍有重叠时逐步提高。还可以减少同一时间进入推力计算的粒子数量。

### 移动推力对象后，推开方向没有改变

推开方向由粒子彼此之间的位置决定。需要从一个中心点向外推动粒子时，使用 `nx 爆炸（nxExplode）`。
