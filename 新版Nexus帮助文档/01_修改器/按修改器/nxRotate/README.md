# nx 旋转（nxRotate）

当前文档版本：NeXus `2026.0.0`

`nx 旋转（nxRotate）`围绕自身轴线改变整批粒子的运动轨迹，形成旋涡、螺旋、旋转力场和向外散开的粒子流。修改器空物体的位置是旋转中心，旋转空物体可以改变轴线方向。

实例模型的原地旋转由 `nx 自旋（nxSpin）` 控制。`nx 旋转（nxRotate）`主要负责改变粒子围绕轴线移动的路径。

## 一条容易跑通的起步方法

1. 使用 `nx 发射器（nxEmitter）` 产生持续移动的粒子。
2. 添加 `nx 旋转（nxRotate）`，将空物体放到想要形成旋涡的中心。
3. 保持力（Force）模式，旋转速度（Rotate Speed）从默认 `180°` 开始。
4. 旋转空物体，确认视口辅助环的轴线指向需要的方向。
5. 粒子甩得太开时，提高吸引力（Attraction）；需要快速散开时降低吸引力或降低逃逸速度（Escape Velocity）。

## 类型（Type）

类型（Type）决定旋转怎样参与粒子运动，默认使用力（Force）。

- 力（Force）：在粒子已有运动上持续加入旋转，风力、重力和其他力仍会参与结果，轨迹常呈逐渐扩大的螺旋
- 速度（Velocity）：旋转更直接地控制粒子速度，轨迹更紧凑，其他改变速度和方向的修改器影响会减弱

需要在原有风力或流场上叠加旋涡时使用力（Force）。需要稳定的环绕路径时，可从速度（Velocity）开始观察。

## 旋转速度（Rotate Speed）和速度乘数（Speed Multiplier）

旋转速度（Rotate Speed）默认每秒 `180°`，控制围绕轴线旋转的基础速度。提高后，粒子更快绕轴运动并形成更紧的螺旋；降低后，旋涡更宽、更缓。使用负值可以反转旋转方向。

速度乘数（Speed Multiplier）默认 `1`，将旋转速度（Rotate Speed）整体相乘。提高后加快当前旋转，降低后减慢；使用负值同样可以反转方向。它适合保留基础旋转速度，同时为不同时间段或不同组建立倍率差异。

## 吸引力（Attraction）

吸引力（Attraction）只在力（Force）模式生效，默认 `10%`。它将粒子拉向旋转轴。

- 提高后，粒子更靠近轴线，旋涡更紧凑
- 降低后，粒子更容易向外扩散
- 使用负值时，粒子会更积极地离开轴线

旋转速度（Rotate Speed）决定绕行快慢，吸引力（Attraction）决定轨迹离轴线多远。这两个参数需要一起观察。

## 角加速（Angular Accel）

角加速（Angular Accel）默认 `0`，随时间持续改变旋转速度。正值会让旋涡越来越快；负值会逐渐减速。点击这一行左侧箭头可展开钳制（Clamp）设置。

### 钳制（Clamp）

钳制（Clamp）默认都不（Neither），可选两者（Both）、最小（Min）或最大（Max）。它决定角加速（Angular Accel）推动旋转速度时是否需要限制速度范围。

最小旋转速度（Min Rotation Speed）默认 `0`，在启用最小（Min）限制后防止旋转继续减慢。最大旋转速度（Max Rotation Speed）默认 `180°`，在启用最大（Max）限制后防止旋涡无限加速。将钳制设为两者（Both）时，旋转速度会保持在两个值之间。

## 逃逸速度（Escape Velocity）

逃逸速度（Escape Velocity）默认 `100`。粒子绕轴加速后，达到该速度便离开 `nx 旋转（nxRotate）` 的旋转场，并沿当时方向继续飞行。

提高后，粒子会在旋涡内停留更久；降低后，粒子更早甩出，适合做逐渐散开的旋涡尾迹。持续看不到粒子逃出时，先降低逃逸速度（Escape Velocity）或提高旋转速度（Rotate Speed）。

## 组（Groups Affected）、映射（Mapping）和衰减（Falloff）

组（Groups Affected）可将旋转限定到指定的 `nx 组（nxGroup）`。映射（Mapping）可以用粒子数据改变旋转参数。衰减（Falloff）使用 `nx 衰减（nxFalloff）` 限制旋涡只在指定空间范围生效。

## 和其他修改器一起使用

`nx 方向（nxDirection）`、`nx 风力（nxWind）`和 `nx 流场修改器（nxFlowField）`可以提供进入旋涡前的主运动；`nx 旋转（nxRotate）`在其上叠加绕轴路径。使用力（Force）模式时，这种组合更容易保留。

`nx 自旋（nxSpin）`负责让实例模型跟随移动方向旋转。`nx 拖尾（nxTrail）`可以把旋涡路径显示成连续线条，更容易判断吸引力和逃逸速度的效果。

## 常见问题

### 看不到旋转

确认 `nx 旋转（nxRotate）`已接入发射器的修改器流程，并检查旋转中心是否离粒子路径过远。先提高旋转速度（Rotate Speed）并观察视口辅助环的轴线方向。

### 粒子绕轴过于松散

在力（Force）模式下提高吸引力（Attraction）。仍然很松散时，降低逃逸速度（Escape Velocity）。

### 粒子速度越来越快

检查角加速（Angular Accel）是否为正值。需要持续加速但限制最高速度时，展开钳制（Clamp）并启用最大（Max）。
