# nx 速度（nxSpeed）

当前文档版本：NeXus `2026.0.0`

`nx 速度（nxSpeed）` 改变粒子的运动速率，同时保留粒子原有运动方向。它使用速度层结构，可以持续增加或减少速度、直接指定速度、按当前速度加速或减速、用曲线输出速度，或在一段时间内从起始速度过渡到结束速度。

新建 `nx 速度（nxSpeed）` 时，当前插件会自动创建一个递增（Incremental）层。默认速度值（Speed Value）是 `1.5`，层强度（Strength）是 `100%`，所以修改器接入粒子流程并播放后会立即逐帧提高粒子速度。

## 一条容易跑通的起步方法

1. 使用 `nx 发射器（nxEmitter）` 产生一批具有明显初始速度的粒子。
2. 添加 `nx 速度（nxSpeed）`，并把它接入这批粒子的修改器流程。
3. 保留自动创建的递增（Incremental）层和默认速度值（Speed Value）`1.5`。
4. 从同一帧播放，观察粒子是否越飞越快、相邻帧之间的前进距离是否持续拉长。
5. 把速度值（Speed Value）改成较小正值，观察加速过程是否变缓。
6. 把层类型（Layer Type）改成绝对（Absolute），继续使用相同速度值（Speed Value），观察粒子是否改为保持统一速率。
7. 需要防止递增层持续加速时，打开限制最大值（Clamp Max）并设置粒子速度最大值（Particle Speed Max）。

比较两种层时应从同一帧重新开始模拟。递增（Incremental）会积累速度，继续播放旧状态会让比较结果混入此前已经增加的速率。

## 先看懂五种速度层

- 范围（Range）：在时间过程中从起始速度过渡到结束速度
- 递增（Incremental）：每帧给当前速度增加或减少固定数值
- 绝对（Absolute）：把粒子当前速率直接设为指定数值
- 指数（Exponential）：按当前速率成比例加速或减速
- 使用样条（Use Spline）：使用速度样条输出速度，并用最大速度控制输出尺度

递增（Incremental）和指数（Exponential）都会随时间积累变化。绝对（Absolute）适合需要固定速率的粒子。范围（Range）适合有明确起止速度和变化时段的效果。

## 层列表与混合

速度层从列表底部向顶部依次处理。上层会继续处理下层已经得到的速率。

- 层启用（Enabled）关闭后，当前层保留在列表里，但不参与计算
- 层类型（Layer Type）决定当前层使用哪种速度算法
- 混合（Blend）决定当前层怎样与下方层结果结合
- 强度（Strength）决定当前层参与结果的比例，默认 `100%`，范围是 `0%` 到 `100%`

强度（Strength）降低后，当前层造成的速度变化随之减弱；设为 `0%` 时，当前层不会改变下方结果。

混合（Blend）提供法线方向（Normal）、添加（Add）、减去（Subtract）、相乘（Multiply）、差值（Difference）、屏幕（Screen）、叠加（Overlay）、最小（Min）和最大（Max）。先用法线方向（Normal）确认每层自身效果，再调整其他混合方式。多层结果难以理解时，从最底层开始逐层启用。

## 每层衰减（Falloff）

每个速度层都有自己的常规（General）页和衰减（Falloff）页。衰减（Falloff）限制当前层在场景中的生效区域，不会同时限制其他速度层。

可以直接添加盒体（Box）、线性（Linear）、球体（Sphere）或噪波（Noise）衰减，也可以把场景中的 `nx 衰减（nxFalloff）` 加入当前层。递增（Incremental）层只在粒子位于衰减区域时持续积累速度变化；粒子在区域中停留越久，累计结果越明显。

## 递增（Incremental）层

递增（Incremental）层每帧把速度值（Speed Value）加入粒子当前速率。当前插件新建修改器时默认使用这一层，速度值默认 `1.5`，变化（Variation）默认 `0%`。

- 速度值为正数时，粒子每帧继续加速
- 正值提高后，每帧增加的速率更大，粒子会更快达到高速
- 正值降低后，加速过程更缓慢
- 速度值为负数时，粒子逐帧减速，持续作用后可以停下

递增（Incremental）层容易让速率快速累积。需要粒子加速后保持在安全范围内时，打开限制最大值（Clamp Max）；需要负值减速但不希望低于某个速率时，打开限制最小值（Clamp Min）。

变化（Variation）范围是 `0%` 到 `100%`。值提高后，不同粒子每帧得到的速度改变量差异更大；保持 `0%` 时，粒子使用统一速度值。

## 绝对（Absolute）层

绝对（Absolute）层把粒子速率直接设为速度值（Speed Value）。它与递增（Incremental）层共用默认速度值 `1.5` 和变化（Variation）`0%`。

- 速度值提高后，粒子直接以更高目标速率运动
- 速度值降低后，粒子直接以更低目标速率运动
- 多个粒子原有速率不同时，变化（Variation）为 `0%` 可以把它们整理到统一目标速率

绝对（Absolute）不会逐帧累加速度值，适合让进入某个区域的粒子统一快慢。它只改变速率大小，粒子原有运动方向会保留。

## 指数（Exponential）层

指数（Exponential）层根据粒子当前速率按比例加速或减速。界面中的加速度（Acceleration）默认值是 `5`。

- 加速度为正数时，当前速率越高，后续增加量越明显，速度会逐渐加快增长
- 正值提高后，加速会更快放大
- 加速度为负数时，粒子会逐渐减速并趋向停止
- 负值绝对值提高后，减速过程更快

指数（Exponential）与递增（Incremental）的主要区别在于：递增层每帧加减固定量，指数层根据当前速率按比例变化。指数层在高速粒子上更容易迅速放大，应配合限制最大值（Clamp Max）观察。

## 公共速度上下限

递增（Incremental）、绝对（Absolute）和指数（Exponential）层都提供速度上下限。

### 限制最小值（Clamp Min）

限制最小值（Clamp Min）默认关闭。开启后，粒子速度最小值（Particle Speed Min）规定当前层允许的最低速率，默认值是 `0`。

- 当前层正在减速时，下限可以防止粒子继续降到指定值以下
- 数值提高后，粒子会保留更高的最低运动速率
- 变化（Variation）提高后，不同粒子的最低速率出现差异

### 限制最大值（Clamp Max）

限制最大值（Clamp Max）默认关闭。开启后，粒子速度最大值（Particle Speed Max）规定当前层允许的最高速率，默认值是 `5`。

- 当前层正在加速时，上限可以防止粒子继续超过指定值
- 数值提高后，粒子可以达到更高速度
- 数值降低后，加速会更早停止在较低上限
- 变化（Variation）提高后，不同粒子的最高速率出现差异

上下限开关关闭时，对应数值不会生效。只设置数值但没有打开开关，速度仍可继续超出该边界。

## 使用样条（Use Spline）层

使用样条（Use Spline）层通过速度样条（Speed Spline）输出速度。默认曲线从左下角线性上升到右上角，最大速度（Speed Max）默认 `3`，变化（Variation）默认 `0%`。

- 抬高曲线某一段后，该段输出的速度会提高
- 压低曲线某一段后，该段输出的速度会降低
- 最大速度（Speed Max）提高后，整条曲线可输出的速度尺度增大
- 最大速度（Speed Max）降低后，整条曲线输出整体减弱
- 变化（Variation）提高后，不同粒子的最大速度出现随机差异

当前插件界面没有为这一层提供单独的时间模式或上下限。需要明确的起止时间时，使用范围（Range）层；需要限制最终最高速率时，可以在后面接入 `nx 限制（nxLimit）` 的速度（Speed）上限。

## 范围（Range）层

范围（Range）层让粒子速度从起始速度（Speed Start）过渡到结束速度（Speed End）。当前插件默认起始速度为 `0`，结束速度为 `1.5`，开始时间（Start Time）为 `0`，结束时间（End Time）为 `60`，各种变化默认 `0%`。

起始速度（Speed Start）提高后，过渡开始时粒子更快；结束速度（Speed End）提高后，过渡完成时粒子更快。起始值高于结束值时形成减速过程，起始值低于结束值时形成加速过程。

### 速度时间（Speed Time）

速度时间（Speed Time）决定这段变化按哪种时间基准推进。当前 Blender 软件（Blender）插件默认使用粒子寿命（Particle Age）。

- 出生时（On Birth）：每个粒子从出生时开始使用范围结果；当前界面只显示结束速度（Speed End）及其变化
- 粒子寿命（Particle Age）：每个粒子按自身出生后的年龄推进，先出生和后出生的粒子各自经历完整过渡
- 帧时间（Frame Time）：按场景时间线推进，同一帧中的粒子共同使用当前过渡位置

粒子寿命（Particle Age）和帧时间（Frame Time）会显示完整的起始速度、结束速度、开始时间、结束时间、时间变化量、钳制模式和缓动曲线。

### 时间范围与变化

开始时间（Start Time）和结束时间（End Time）共同定义主要过渡区间。区间缩短后，粒子更快到达结束速度；区间拉长后，速度变化更缓慢。

时间变化量（Time Variation）范围是 `0%` 到 `100%`。值提高后，不同粒子的过渡时机更分散；设为 `0%` 时，粒子按统一时间设置变化。

起始速度（Speed Start）和结束速度（Speed End）各自也有变化（Variation）。提高后，不同粒子的起点或终点速率会出现差异。

### 缓动（Ease）

缓动（Ease）曲线决定起始速度到结束速度之间的变化节奏。曲线前段抬高时，速度会更早接近结束值；前段压低时，变化会更多集中在后半段。默认直线表示均匀过渡。

### 钳制模式（Clamp Mode）

钳制模式（Clamp Mode）决定时间位于过渡区间外时怎样处理，默认是钳制（Clamp）。

- 钳制（Clamp）：开始前保持起始速度，结束后保持结束速度，当前层在整条时间线上持续有效
- 在范围内钳制（Clamp In Range）：只在开始时间和结束时间之间生效，区间外当前层不影响速度
- 重复（Repeat）：过渡结束后从头重复这段变化
- 继续（Continue）：超过时间边界后继续沿曲线趋势变化

只想让速度修改发生在指定时段时，选择在范围内钳制（Clamp In Range）。需要持续循环加速和减速时，可以选择重复（Repeat）并调整缓动（Ease）曲线。

## 修改器启用（Enabled）

修改器启用（Enabled）控制整个 `nx 速度（nxSpeed）` 是否参与粒子流程。关闭后，所有速度层停止改变粒子速率，层和参数仍会保留。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 发射器（nxEmitter）` 提供粒子出生时的初始速度和方向。`nx 速度（nxSpeed）` 接入后继续改变速率大小，不会替代发射方向。

初始速度为 `0` 时，绝对（Absolute）层可以直接给粒子设置运动速率；粒子仍需要已有方向才能形成可见位移。

### 和力修改器

`nx 重力（nxGravity）`、`nx 风力（nxWind）`、`nx 湍流（nxTurbulence）` 和 `nx 涡度（nxVorticity）` 会持续改变粒子速度。绝对（Absolute）层可能把这些修改器产生的速率差异重新整理为统一数值，递增（Incremental）和指数（Exponential）层会在已有速率上继续变化。

### 和 nx 阻力（nxDrag）

`nx 阻力（nxDrag）` 根据粒子状态逐渐减速，`nx 速度（nxSpeed）` 可以持续增加、减少或指定速率。两者同时使用时，最终结果取决于各自作用强度及粒子在衰减区域中的停留时间。

### 和 nx 限制（nxLimit）

`nx 速度（nxSpeed）` 主动改变粒子速率。`nx 限制（nxLimit）` 的速度（Speed）层规定允许的最低和最高速率。

需要加速并控制最高速度时，可以先用递增（Incremental）或指数（Exponential）产生变化，再用限制修改器设置最终上限。速度层自身的限制最大值（Clamp Max）只约束当前速度层，限制修改器适合控制整段流程的最终边界。

### 和 nx 自旋（nxSpin）

`nx 速度（nxSpeed）` 改变运动快慢，不会自动设置实例模型的真实旋转。模型需要继续朝向运动方向时，使用 `nx 自旋（nxSpin）` 的切向（Tangential）层。

### 和 nx 拖尾（nxTrail）

`nx 拖尾（nxTrail）` 可以把速度变化显示成连续轨迹。递增加速时，相邻轨迹点的距离会逐渐拉大；减速时，轨迹点会逐渐靠近。

### 和 nx 缓存（nxCache）

修改层类型、速度值、时间、曲线或层顺序后，旧缓存仍可能回放此前结果。参数已经改变但轨迹没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 添加后粒子突然越来越快

新建修改器默认包含递增（Incremental）层，速度值（Speed Value）为 `1.5`，会每帧增加速率。降低速度值，打开限制最大值（Clamp Max），或改用绝对（Absolute）层。

### 粒子完全没有速度变化

按下面顺序检查：

1. `nx 发射器（nxEmitter）` 是否正在产生粒子
2. `nx 速度（nxSpeed）` 是否已经接入同一批粒子的修改器流程
3. 修改器启用（Enabled）是否打开
4. 当前速度层启用（Enabled）是否打开
5. 强度（Strength）是否大于 `0%`
6. 当前层数值是否会改变粒子现有速率
7. 当前层衰减（Falloff）是否排除了粒子所在区域
8. `nx 缓存（nxCache）` 是否仍在回放旧结果

### 设置负速度值后，粒子没有立刻停止

递增（Incremental）层每帧减去固定速率，需要经过若干帧才会停下。需要更快停止时提高负值绝对值，并打开限制最小值（Clamp Min），把粒子速度最小值（Particle Speed Min）设为 `0`。

### 设置了最大速度却仍然超过上限

先确认限制最大值（Clamp Max）已经打开。速度层内部上限只控制当前层结果，后续其他修改器仍可能继续加速；需要限制整段流程的最终速度时，使用 `nx 限制（nxLimit）` 的速度（Speed）上限。

### 范围层在所有粒子上不同步

检查速度时间（Speed Time）。粒子寿命（Particle Age）按每个粒子自己的年龄推进，发射时间不同就会处于不同过渡位置；需要同一帧共同变化时，选择帧时间（Frame Time）。

### 范围层只在一段时间内有作用

检查钳制模式（Clamp Mode）是否设为在范围内钳制（Clamp In Range）。这个模式会在时间区间外关闭当前层影响。需要区间外保持端点速度时，选择钳制（Clamp）。

### 多层速度结果难以判断

层从底部向顶部处理。先关闭上层，从最底层开始逐层恢复，并把混合（Blend）设为法线方向（Normal）、强度（Strength）设为 `100%`。确认每层单独结果后，再调整混合方式。
