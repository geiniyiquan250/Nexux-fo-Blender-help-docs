# nx 高分辨率（nxUpres）

当前文档版本：NeXus `2026.0.0`

`nx 高分辨率（nxUpres）`把低粒子数量源模拟的运动和属性传给独立的高粒子数量目标发射器。目标保留自己的密集粒子数量，同时读取附近源粒子的距离加权平均值。

## 添加和起步

1. 先模拟或缓存一个低数量 `nx 发射器（nxEmitter）`，加入源（Source）列表。
2. 创建独立的高数量发射器，加入目标（Destination）列表。
3. 保持默认位置 `0%`、速度 `100%`，播放观察密集目标是否跟随源运动。
4. 再按需要传递半径、质量、颜色和组。

同一个发射器不能同时作为源和目标。源或目标列表为空时没有可传递结果。

## 已启用（Enabled）

已启用（Enabled）控制全部高分辨率传递。两张发射器列表中的条目也可以单独临时关闭。

## 源（Source）和目标（Destination）

源（Source）通常放低数量、低成本模拟；目标（Destination）通常放高数量输出。修改器为每颗目标粒子寻找附近源粒子，并混合它们的属性。

### 强度（Strength）

强度（Strength）控制源属性接管目标的整体比例，默认 `100%`。降低后目标保留更多自身状态；设为 `0%`时忽略源；`100%`时启用的属性完整采用源平均结果。

### 位置、速度、半径、质量和颜色

这些滑块分别控制对应属性的混合比例。位置（Position）默认 `0%`，目标保持自身分布；速度（Velocity）默认 `100%`，目标跟随源运动；半径（Radius）、质量（Mass）和颜色（Color）默认都是 `0%`。

提高某项只会加强该属性的传递。例如只提高速度可以保留密集目标的位置分布，同时让它跟随低数量模拟运动。

### 组（Group）

组（Group）默认关闭。开启后，每颗目标粒子会加入最近源粒子所属的 `nx 组（nxGroup）`。

### 最大数量（Max Count）

最大数量（Max Count）控制每颗目标粒子最多混合多少颗最近源粒子，默认 `3`，范围 `1`到 `64`。提高后平均结果更平滑、更扩散，搜索和混合成本也会增加；降低后更接近少数近邻的局部运动。

### 限制距离（Limit Distance）和最大距离（Max Distance）

限制距离（Limit Distance）默认关闭，此时搜索距离不受限。开启后，最大距离（Max Distance）生效，默认 `2 m`；范围外的源粒子会被忽略。

降低最大距离会让目标只读取紧邻源，可能出现没有可用源的区域；提高后能跨更远距离传递运动。

### 推力（Push）和推力距离（Push Distance）

推力（Push）默认关闭。开启后会把目标粒子互相推开，减少它们被位置传递拉向源流后挤成一团。推力距离（Push Distance）默认 `200%`，提高后目标间距扩大；降低后保持更紧密。

## 组（Groups Affected）

组（Groups Affected）可以把高分辨率传递限制到指定粒子组。

## 映射（Mapping）和衰减（Falloff）

映射（Mapping）可用粒子数据驱动传递参数；衰减（Falloff）可把作用限制在指定空间区域。

## 常见问题

### 密集目标没有跟随源运动

确认源与目标是不同发射器、两张列表条目已启用，并检查速度（Velocity）和强度（Strength）大于 `0%`。

### 目标粒子向源流中心塌缩

降低位置（Position）传递，或开启推力（Push）并逐步调整推力距离（Push Distance）。

### 结果过度平滑

降低最大数量（Max Count），让每颗目标粒子只读取更少的近邻源粒子。
