# nx 涡度（nxVorticity）

当前文档版本：NeXus `2026.0.0`

`nx 涡度（nxVorticity）` 读取流体粒子及其周围粒子的速度，再给粒子施加涡度约束力，让已有的流动形成更明显的旋流和回卷。它适合加强液体中的局部翻滚、喷流边缘的小涡流和较大范围的平滑回旋。

这个修改器会放大粒子运动中已经存在的旋转趋势。粒子之间具有不同速度或运动方向时，效果更容易观察；粒子完全静止，或整批粒子始终以相同速度沿同一方向移动时，能够形成的旋流会很少。

## 一条容易跑通的起步方法

1. 使用 `nx 发射器（nxEmitter）` 产生粒子，并让 `nx 流体（nxFluids）` 处理这批粒子。
2. 添加 `nx 涡度（nxVorticity）`，并把它接入同一批粒子的修改器流程。
3. 保持半径（Radius）`100%`、强度（Strength）`1%`、力限制（Force Limit）`1000`。
4. 播放时间线，观察流体边缘、喷流弯折处和粒子速度变化明显的位置。
5. 临时关闭已启用（Enabled），对比局部回旋是否减弱。
6. 需要更明显的旋流时，每次小幅提高强度（Strength）；运动开始迅速放大时，降低力限制（Force Limit）。
7. 效果确认后，再用半径（Radius）选择细小旋流或大范围平滑旋流。

观察粒子点时难以判断旋流形状，可以临时使用 `nx 拖尾（nxTrail）` 显示连续轨迹，或使用 `nx 网格化（nxMesher）` 查看流体表面的回卷变化。

## 半径（Radius）

半径（Radius）控制每个粒子搜索周围粒子的范围。修改器会使用这个范围内的粒子速度计算涡度力。当前插件默认值是 `100%`，可输入范围是 `0%` 到 `1000%`。

- 值低于 `100%` 时，搜索范围缩小，画面中更容易出现数量较多、彼此分开的细小旋流
- 值提高到 `100%` 以上后，更多邻近粒子的速度会参与计算，旋流会变得更大、更连续、更平滑
- 值为 `0%` 时，搜索范围收缩到零，通常看不到由周围粒子速度计算出的涡度效果

半径（Radius）也会影响计算量。较低数值搜索的邻居更少，模拟通常更快；较高数值会扩大每个粒子的搜索范围，粒子数量较多时计算时间会增加。

流体表面充满零散的小卷曲时，可以提高半径（Radius），让局部运动合并成更大的旋流。旋流范围过大、局部细节被抹平时，可以降低半径（Radius）。

## 强度（Strength）

强度（Strength）控制涡度力的大小。当前插件默认值是 `1%`，最小值是 `0%`。

- 值提高后，已有旋流会更快变明显，粒子轨迹的弯折和回卷幅度也会增大
- 值降低后，旋流对原有流动的改变会减弱
- 值为 `0%` 时，修改器不会施加涡度力

涡度力会随模拟持续累积。强度（Strength）较高时，旋流可能逐帧增强，最终出现粒子速度快速升高、流体散开或运动难以控制。调整时可以从默认值开始小幅增加，并继续播放一段时间观察累积结果。

## 力限制（Force Limit）

力限制（Force Limit）规定涡度效果最多可以建立多大的力。它会限制强度（Strength）最终产生的涡度力，帮助高强度设置保持可控。当前插件默认值是 `1000`，范围是 `0` 到 `1000`。

- 值提高后，强度（Strength）可以建立更大的涡度力，旋流能够继续增强
- 值降低后，涡度力会更早到达上限，局部运动不容易继续猛烈放大
- 值为 `0` 时，涡度力被限制为零，粒子不会得到这个修改器产生的力

默认值 `1000` 给强度（Strength）保留了很大的发挥空间。保持默认强度（Strength）`1%` 时，通常可以先保留这个值；提高强度后出现粒子突然加速、旋流持续扩大或模拟失控时，再逐步降低力限制（Force Limit）。

## 三个参数怎样一起判断

- 半径（Radius）决定每个粒子会参考多大范围内的邻居速度，也决定旋流细小分散还是宽大平滑
- 强度（Strength）决定计算出的旋流趋势会以多大的力施加到粒子上
- 力限制（Force Limit）给这股力设置最终上限，限制强度继续累积后的最大作用

半径（Radius）主要改变旋流的空间尺度，强度（Strength）和力限制（Force Limit）共同决定作用力度。强度很高但力限制很低时，实际涡度力会被力限制压住；力限制很高但强度很低时，粒子仍只会得到较弱的涡度力。

可以按下面顺序调整：

1. 先用半径（Radius）选定希望看到的小旋流或大旋流。
2. 再提高强度（Strength），让旋流达到需要的明显程度。
3. 运动随时间不断放大时，降低力限制（Force Limit）控制最大作用。

## 已启用（Enabled）

已启用（Enabled）控制 `nx 涡度（nxVorticity）` 是否参与粒子模拟。关闭后，粒子会保留其他修改器产生的运动，当前修改器不会继续施加涡度力。

这个开关适合对比涡度加入前后的流动。关闭后仍然看到旋转轨迹时，旋转可能来自流体自身运动、流场、湍流或其他力修改器。

## 视口可见（Visible in Editor）

当前插件的 `nx 涡度（nxVorticity）` 没有专用的视口辅助图形。切换视口可见（Visible in Editor）不会改变涡度计算，也不会隐藏粒子模拟结果。

## 组（Groups Affected）

组（Groups Affected）把 `nx 涡度（nxVorticity）` 限制到指定的 `nx 组（nxGroup）`。列表为空时影响所有可用粒子；加入组后，只加强这些组中的旋流。

## 映射（Mapping）

映射（Mapping）用粒子自身的数据驱动可映射的涡度参数，让不同粒子得到不同程度的旋流增强。具体可映射参数以当前映射列表为准。

## 衰减（Falloff）

衰减（Falloff）使用一个或多个 `nx 衰减（nxFalloff）` 对象限制涡度的作用区域。粒子离开有效衰减区域后，当前修改器不再加强它的旋流。

## 和其他修改器一起使用

### 和 nx 发射器（nxEmitter）

`nx 涡度（nxVorticity）` 需要接入正在产生粒子的修改器流程。发射器已经产生粒子但涡度没有效果时，先检查发射器的修改器列表是否包含它。

### 和 nx 流体（nxFluids）

`nx 涡度（nxVorticity）` 用于加强流体粒子已有运动中的旋流。流体发生转向、碰撞、挤压或速度差异的位置更容易产生可见结果。

强度（Strength）提高后流体迅速散开时，先降低强度（Strength）和力限制（Force Limit），再检查 `nx 流体（nxFluids）` 自身的稳定性设置。

### 和 nx 流场修改器（nxFlowField）

`nx 流场修改器（nxFlowField）` 可以先建立整体流动方向和弯曲路径，`nx 涡度（nxVorticity）` 会根据邻近粒子的实际速度继续加强局部旋流。

需要清楚的主流向时，先让流场形成主要运动，再从较低涡度强度开始增加。

### 和 nx 湍流（nxTurbulence）

`nx 湍流（nxTurbulence）` 会给粒子增加不同尺度的速度变化，这些速度差异可以为涡度计算提供更丰富的局部运动。两者强度都较高时，轨迹可能很快变得混乱。

可以先单独调整湍流的运动尺度，再启用较低强度的涡度，观察哪些局部弯折开始形成连续旋流。

### 和 nx 限制（nxLimit）

力限制（Force Limit）只限制当前涡度效果建立的力。`nx 限制（nxLimit）` 的速度（Speed）层可以继续限制粒子从所有修改器得到的最终速度。

希望保留强烈旋流，同时控制粒子最高速度时，可以同时使用两者：先用力限制（Force Limit）控制涡度力，再用速度（Speed）层控制最终运动速度。

### 和 nx 拖尾（nxTrail）

`nx 拖尾（nxTrail）` 可以把粒子路径显示成连续轨迹。比较半径（Radius）时，重点观察旋流是大量分散的小弯圈，还是范围更大的平滑回转。

### 和 nx 网格化（nxMesher）

`nx 网格化（nxMesher）` 会把流体粒子转成连续表面。粒子轨迹已经形成旋流但表面变化不明显时，需要同时检查网格半径和平滑设置，因为网格化可能合并细小的局部变化。

### 和 nx 缓存（nxCache）

修改半径、强度或力限制后，旧缓存仍可能回放此前结果。参数已经改变但旋流没有更新时，检查 `nx 缓存（nxCache）` 是否仍在读取旧数据。

## 常见问题

### 粒子完全没有出现旋流

按下面顺序检查：

1. `nx 发射器（nxEmitter）` 是否正在产生粒子
2. `nx 涡度（nxVorticity）` 是否已经接入同一批粒子的修改器流程
3. 已启用（Enabled）是否打开
4. 强度（Strength）是否大于 `0%`
5. 力限制（Force Limit）是否大于 `0`
6. 半径（Radius）是否大于 `0%`
7. 粒子是否已经具有可供计算的运动和局部速度差异
8. `nx 缓存（nxCache）` 是否仍在回放旧结果

### 旋流太碎，像许多互不相连的小卷曲

提高半径（Radius），让每个粒子参考更大范围内的邻居速度。旋流会逐渐扩大并变得平滑，计算时间也可能增加。

### 旋流范围太大，局部细节消失

降低半径（Radius），让涡度计算回到更小的邻域。需要恢复明显程度时，再小幅提高强度（Strength）。

### 粒子越转越快，最后散开

涡度力会持续累积。先降低强度（Strength），再降低力限制（Force Limit）。多个力修改器同时作用时，还可以使用 `nx 限制（nxLimit）` 控制最终速度。

### 提高强度后，效果几乎不再增强

检查力限制（Force Limit）是否较低。涡度力达到这个上限后，继续提高强度（Strength）也会受到限制。

### 提高半径后模拟明显变慢

较大的半径（Radius）会让每个粒子搜索更多邻居。降低半径，或先用较少粒子确定旋流尺度，再恢复正式粒子数量。
